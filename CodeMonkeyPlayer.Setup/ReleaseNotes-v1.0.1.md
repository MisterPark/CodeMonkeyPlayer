# CodeMonkey Player 1.0.1

Windows용 동영상 플레이어의 첫 설치 패키지 릴리스입니다.

- 아이콘 기반 재생 컨트롤, 클릭·드래그 탐색, 음량·음소거 및 재생 목록
- 영상 클릭으로 재생·일시 정지, 더블클릭으로 전체 화면 전환
- 전체 화면에서 하단 조작부 자동 숨김
- `,` / `.` 프레임 이동과 코덱별 이동 보정
- `%LocalAppData%\CodeMonkeyPlayer\CodeMonkeyPlayer.ini`에 사용자 설정 저장
- 창 위치·크기·최대화 상태 복원 및 화면 밖 좌표 보정
- MSI 설치, 시작 메뉴·바탕화면 바로가기, 업그레이드·제거 지원

## 설치

`CodeMonkeyPlayer-Setup.msi`를 내려받아 실행하세요. 설치에는 관리자 권한이 필요합니다.
Windows의 .NET Framework 4.8 이상과 Windows Media Player(레거시) 구성 요소가 필요합니다.
설치 파일과 실행 파일에는 코드 서명이 없습니다.

## 참고

지원하는 미디어 형식은 설치된 WMP 코덱에 따릅니다. 가변 프레임 영상과 일부 코덱은 정밀한 프레임 이동에 한계가 있습니다.
기존 실행 파일 옆의 INI는 새 사용자 설정이 없을 때 가져옵니다. 개인 설정은 업데이트·제거 시 유지합니다.

설정 저장·이전·창 복원 테스트와 MSI 데이터베이스 검증을 통과했습니다.
